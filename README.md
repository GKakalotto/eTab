# eTab - 空白新建标签页

用一个简洁的搜索页面替换浏览器默认的新标签页。

## 为什么做这个？

Edge 浏览器默认的新标签页充满了新闻推荐、广告和各种杂乱的信息流，非常不简洁。eTab 提供一个干净、无干扰的替代方案 — 只有搜索框，打开新标签页就能直接搜索。

## 功能

- **多搜索引擎** — 内置 Google、Bing、Baidu，一键切换
- **亮色 / 暗色主题** — 右上角按钮切换，偏好自动保存
- **智能跳转** — 输入网址自动打开网站，输入关键词自动搜索
- **无需权限** — 不收集任何数据，开箱即用

## 使用方法

1. 在搜索框输入内容，按回车或点击「搜索」
2. 点击搜索框左侧的彩色圆点可切换搜索引擎
3. 点击右上角 🌙 / ☀️ 按钮切换亮色/暗色模式
4. 直接输入网址（如 `https://example.com` 或 `example.com`）会自动跳转
